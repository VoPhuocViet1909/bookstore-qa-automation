# BUG-007: Đặt hàng COD luôn thất bại do lỗi khi tạo vận đơn GHN làm rollback cả đơn hàng

- **Phát hiện khi:** chạy bộ test Selenium (TC-UI-CHK-01 Đặt hàng COD thành công)
- **Mức độ:** Critical | **Ưu tiên:** High
- **Môi trường:** Local, backend docker-compose (GHN dùng token giả), frontend Next.js (dev)

## Các bước tái hiện
1. Đăng nhập một khách hàng đã có địa chỉ giao hàng
2. `POST /api/cart/add` với một sách còn hàng
3. `POST /api/orders/checkout` với `{ "addressId": "<id>", "paymentMethod": "COD", "bookIds": ["<bookId>"] }`
4. `GET /api/orders`

## Kết quả mong đợi
Tạo đơn hàng trạng thái `PENDING`, trả về `code: 1000` kèm thông tin đơn. Nếu không tạo được vận đơn GHN
thì đơn vẫn được lưu (code đã ghi chú: *"Don't fail the order if shipment creation fails"*).

## Kết quả thực tế
- Response: HTTP 200, `{"code":4005,"message":"Transaction silently rolled back because it has been marked as rollback-only"}`
- `GET /api/orders` trả về danh sách rỗng: **không có đơn nào được lưu**.

Log backend:
```
WARN  OrderServiceImpl   : Failed to calculate shipping fee from GHN, using default 30000.0
ERROR ShipmentServiceImpl: Failed to create shipment for order ee715d53-...
java.lang.NullPointerException: Cannot invoke "java.util.List.stream()" because the return value of
  "Order.getOrderItems()" is null
    at ShipmentServiceImpl.buildGhnRequest(ShipmentServiceImpl.java:368)
    at ShipmentServiceImpl.createShipmentOrder(ShipmentServiceImpl.java:298)
    at OrderServiceImpl.checkout(OrderServiceImpl.java:257)
```

## Nguyên nhân (phân tích)
1. `OrderServiceImpl.checkout` lưu `orderItems` bằng `orderItemRepository.saveAll(...)` nhưng không gán vào
   `order.setOrderItems(...)`. Khi gọi `shipmentService.createShipmentOrder(order)`, `order.getOrderItems()` là `null`
   nên `buildGhnRequest` ném `NullPointerException`.
2. `createShipmentOrder` có `@Transactional` (tham gia transaction của `checkout`). Exception đi qua proxy này
   đánh dấu transaction là *rollback-only*. `checkout` bắt exception để "không làm hỏng đơn", nhưng khi commit thì
   Spring vẫn rollback toàn bộ (`UnexpectedRollbackException`).

Phí ship đã fallback đúng về 30.000₫; lỗi nằm ở bước tạo vận đơn, xảy ra với **mọi** đơn COD.

## Ảnh hưởng
Không đặt được đơn COD nào. Kết hợp với [BUG-008](BUG-008.md), khách còn được báo "Đặt hàng thành công" và bị xoá giỏ hàng.

## Đề xuất
- Gán danh sách sản phẩm vào đơn trước khi tạo vận đơn: `order.setOrderItems(orderItems)`.
- Tạo vận đơn trong transaction riêng (`@Transactional(propagation = REQUIRES_NEW)`) hoặc sau khi commit
  (`@TransactionalEventListener(phase = AFTER_COMMIT)`) để lỗi GHN không kéo theo rollback đơn hàng.

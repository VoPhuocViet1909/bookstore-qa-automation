# BUG-002: ID sách sai định dạng trả về 500 thay vì 400

- **Test case:** TC-API-BOOK-04
- **Mức độ:** Medium | **Ưu tiên:** Medium
- **Môi trường:** Local (docker-compose)

## Các bước tái hiện
1. Gửi `GET /api/books/not-a-uuid`

## Kết quả mong đợi
HTTP **400 Bad Request** (tham số không hợp lệ).

## Kết quả thực tế
HTTP **500 Internal Server Error**.

## Ghi chú
Backend chưa validate kiểu tham số đường dẫn, hoặc chưa xử lý exception khi chuyển đổi kiểu.

# BUG-009: Mật khẩu người dùng bị ghi ra console trình duyệt khi đăng nhập

- **Phát hiện khi:** chạy test bảo mật TC-UI-LOGIN-08 (Selenium) / TC-E2E-LOGIN-05 (Playwright)
- **Mức độ:** High | **Ưu tiên:** High | **Loại:** Security (OWASP A09 - Security Logging Failures)
- **Môi trường:** Local, frontend Next.js (dev)

## Các bước tái hiện
1. Mở `http://localhost:3000/login`, mở DevTools (F12) → tab Console
2. Nhập tên đăng nhập và mật khẩu đúng, bấm "Đăng nhập"

## Kết quả mong đợi
Không có dữ liệu nhạy cảm (mật khẩu, token) nào xuất hiện trong console.

## Kết quả thực tế
Console in ra toàn bộ body của request đăng nhập, gồm cả mật khẩu dạng rõ:
```
POST request body (raw): {username: 'se_cus_...', password: 'Test@123'}
POST request body (stringified): {
  "username": "se_cus_...",
  "password": "Test@123"
}
```

## Nguyên nhân (phân tích)
`lib/api-client.ts` dòng 140-143, hàm `post()` log mọi request body bằng `console.log` để debug,
không lọc trường nhạy cảm. Ảnh hưởng mọi API POST: đăng nhập, đăng ký, đổi mật khẩu, đặt lại mật khẩu.

## Ảnh hưởng
Mật khẩu lộ cho bất kỳ ai nhìn được màn hình/DevTools (máy dùng chung, chia sẻ màn hình), cho extension
trình duyệt đọc console, và cho các công cụ thu thập log phía client.

## Đề xuất
Xoá các dòng `console.log` request body, hoặc chỉ log khi `NODE_ENV === "development"` và che các trường
`password`, `newPassword`, `token`, `otp`.
